# CityVision AI — Smart City Traffic Command Center

A competition-ready React.js frontend prototype for the SIH city-wide ANPR, vehicle tracking and traffic analytics platform.

## Pages (exactly 9)
1. Dashboard
2. Live Camera Feed
3. Vehicle Search & Tracking
4. GIS Traffic Map
5. Traffic Analytics
6. Alerts
7. Camera Management
8. Reports
9. Settings

## Stack
React, Vite, Framer Motion, Lucide React, Recharts.

## Run locally
```bash
npm install
npm run dev
```

The UI uses realistic demo data only. Camera video tiles are visual placeholders for live streams and the GIS map is a stylized prototype surface intended for frontend demonstration.
